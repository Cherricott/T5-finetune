# T5-finetune
Folder Grammar Correction:
- modeltest.ipynb: Code for fine tuning the T5 Small.
- lang8dataset.csv: Lang-8 Dataset for fine tuning the model.
- modeltest.ipynb: Code for testing the model with the user's input.
- [Model](https://drive.google.com/drive/folders/1v88f9pzw7dpoyKhrL2g6utJ5wPZBghKt?usp=sharing): Google Drive Link of the model

To test the model, you need:
1. Download the modeltest.ipynb.
2. Download the [Model](https://drive.google.com/drive/folders/1v88f9pzw7dpoyKhrL2g6utJ5wPZBghKt?usp=sharing).
3. Change the local link to the folder "Model" in modeltest.ipynb.
4. Input the error sentence you want to correct.
5. Receive the output from the model.
